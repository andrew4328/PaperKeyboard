### Paper Keyboard

Who wants to make a paper keyboard with us?

https://github.com/user-attachments/assets/f57ef7b2-e74b-4733-a4a4-21d8a3593ca0

* print a piece of paper with clearly legible symbols
* OR project a legible layout onto a surface
* tap the symbols in visibility of a camera
* camera registers key presses as key ups, key holds, key downs
* finger differentiation allows for various modifiers for different hands / fingers
